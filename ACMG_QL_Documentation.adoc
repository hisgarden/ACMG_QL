== Overview

The ACMG Quarry Lakes Demonstration Garden project is a modern web application built to showcase and catalog plants from the UC Davis Arboretum and Community Gardens' demonstration site at Quarry Lakes Regional Recreation Area. The site serves as both an educational resource and a practical plant identification tool for visitors, gardeners, and botanical enthusiasts.

=== Mission Statement

To provide an accessible, searchable digital catalog of native and adapted plants thriving in the San Francisco Bay Area climate, promoting sustainable gardening practices and environmental stewardship.

=== Key Features

* **Interactive Plant Catalog** - Searchable database with 200+ plant species
* **Garden Categories** - Native, Mediterranean, Grasses, Sensory, and OPAC plants
* **Mobile-Responsive Design** - Optimized for all devices
* **Real-time Search & Filtering** - Find plants by name, characteristics, and requirements
* **Dynamic Data Integration** - Live updates from Google Sheets
* **Comprehensive Testing** - Automated link validation and build verification

== Troubleshooting Guide

=== Common Issues

==== Build Failures

**Symptom**: `yarn build` fails with module errors

**Solutions**:
1. Clear cache and reinstall dependencies:
+
[source,bash]
----
rm -rf .yarn node_modules yarn.lock
yarn install
----

2. Check Node.js version compatibility
3. Verify system dependencies (vips, etc.)

==== Google Sheets Connection Issues

**Symptom**: No plant data displayed, "No plant data available" message

**Diagnosis Steps**:
1. Verify `.env` file contains correct API credentials
2. Check Google Sheets API quota limits
3. Confirm sheet structure matches expected schema
4. Test API connectivity manually

**Solutions**:
[source,bash]
----
# Test API connection
curl "https://sheets.googleapis.com/v4/spreadsheets/{SHEET_ID}?key={API_KEY}"
----

==== Link Testing Failures

**Symptom**: `yarn test:links` reports broken links

**Common Causes**:
* Development server not running
* Incorrect route definitions
* Missing page components
* GraphQL query errors

**Resolution Process**:
1. Ensure dev server is running at http://localhost:8080
2. Check console for GraphQL errors
3. Verify all page components exist
4. Review link-test-results.json for specific failures
